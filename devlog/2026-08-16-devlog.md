## [知識庫核心模組開發 - 全格式檔案解析、語法感知切分與存儲檢索] [13:26]

### 開發目標
- 支援所有格式檔案儲存與解析（包含 Markdown、各程式語言原始碼/設定檔、PDF、Word、Excel/CSV、純文字等）。
- 建立工廠模式解析器（Parser Factory）與語法/章節感知切片機制（Chunking Strategy）。
- 建立資料庫模型（`kb_documents`, `kb_chunks`）、RESTful API 與後端單元測試。

### 完成項目
- [x] **[資料庫模型與擴充支援]**：
  - `backend/src/schemas/kb.schema.ts`: 建立 `kb_documents` 與 `kb_chunks` 表結構（支援 pgvector 自定義欄位與 JSONB metadata）。
  - `backend/src/schemas/schema.ts`: 匯出知識庫模型。
  - `backend/src/utils/seed.ts`: 註冊表格初始化 SQL。
- [x] **[多格式解析器工廠架構]**：
  - `backend/src/services/parsers/types.ts`: 定義解析與切片通用介面。
  - `backend/src/services/parsers/base.parser.ts`: Token 估算、滑動視窗切分演算法。
  - `backend/src/services/parsers/markdown.parser.ts`: Markdown 標題階層樹切分與代碼塊保護。
  - `backend/src/services/parsers/code.parser.ts`: 支援 TS/JS/Py/Go/Java/SQL/JSON/YAML 等程式語言，感知語法邊界與自動行號前綴標註。
  - `backend/src/services/parsers/pdf.parser.ts`: 使用 `pdf-parse` 抽取 PDF 內文與分頁。
  - `backend/src/services/parsers/word.parser.ts`: 使用 `mammoth` 抽取 Word 文檔結構。
  - `backend/src/services/parsers/spreadsheet.parser.ts`: 使用 `xlsx` 抽取試算表並轉換為 Markdown 表格。
  - `backend/src/services/parsers/plaintext.parser.ts`: 純文字與設定檔兜底解析。
  - `backend/src/services/parsers/index.ts`: `DocumentParserFactory` 工廠分發入口。
- [x] **[資料存取與業務邏輯]**：
  - `backend/src/repositories/kb.repository.ts`: 實作文檔 CRUD、軟刪除、切片批次寫入與全文/關鍵字檢索。
  - `backend/src/services/kb.service.ts`: 檔案上傳寫入磁碟、調用解析工廠切片、狀態管理與檢索。
  - `backend/src/controllers/kb.controller.ts`: RESTful 控制器（支援 Multer 上傳）。
  - `backend/src/index.ts`: 註冊 `/api/v1/kb/...` 路由。
- [x] **[自動化單元測試]**：
  - `backend/tests/kb.test.ts`: 涵蓋 Markdown、TS/JS 代碼、Python、SQL、CSV 表格、純文字解析與工廠分發測試，7/7 測試案例 100% 通過。
