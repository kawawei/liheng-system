```mermaid
    Delivered --> End([結案歸檔 / 續簽維護約]):::level1
```

## 4. 多階段收款、發票開立與支出毛利核銷流程圖 (Finance Flow)

```mermaid
graph TD
    classDef level1 fill:#f97316,stroke:none,color:white;
    classDef level2 fill:#0d9488,stroke:none,color:white;
    classDef level3 fill:#8b5cf6,stroke:none,color:white;
    classDef level4 fill:#ec4899,stroke:none,color:white;

    subgraph 收入與多階段收款流程
        TermCreated[建立多階段收款期程 REC-YYYYMMDD-XXXX]:::level1 --> PendingInv[狀態: 待請款]:::level2
        PendingInv --> CheckDate{預計請款日是否到達?}:::level2
        CheckDate -->|是| IssueInvoice[管理員開立發票: 填寫發票號碼與日期]:::level3
        IssueInvoice --> InvoicedState[狀態變更為: 已請款]:::level3
        InvoicedState --> ClientPay{客戶是否完成匯款入帳?}:::level2
        ClientPay -->|是| ConfirmReceive[核銷入帳: 選擇公司銀行帳戶與實收金額]:::level1
        ConfirmReceive --> ReceivedState[狀態變更為: 已入帳]:::level1
        ClientPay -->|否且逾期| OverdueState[狀態變更為: 已逾期 醒目警告]:::level4
    end

    subgraph 支出提報與毛利結算
        ExpenseSubmit[工程師/管理員提報支出: 伺服器/API/外包]:::level2 --> EXPCode[發號: EXP-YYYYMMDD-XXXX]:::level3
        EXPCode --> AttachReceipt[上傳發票/收據憑證]:::level3
        AttachReceipt --> ExpensePaid[管理員核銷付款: 狀態變更為 已付款]:::level1
    end

    ReceivedState --> ProfitCalculate[專案實際毛利 = 已入帳總額 - 專案總支出]:::level1
    ExpensePaid --> ProfitCalculate
    ProfitCalculate --> ExportReport[匯出標準 Excel / CSV 收支清冊]:::level3
```

## 5. LINE 專案群組協同與 AI 雙向處理時序圖 (Social & AI Agent Sequence)

```mermaid
sequenceDiagram
    autonumber
    actor Client as 客戶 (個人 LINE)
    actor RD as 工程師 / 業務 (個人 LINE)
    participant LineGroup as LINE 專案討論群組
    participant LineBot as LINE 官方 Bot
    participant Backend as 內部系統後台 (Node.js)
    participant AI as AI 智能分析引擎
    actor Admin as 管理員 (內部 Web 系統)

    Note over Client,RD: 1. 業務建立 LINE 專案群組並邀請 LINE Bot 入群
    LineBot->>Backend: Webhook: join 事件 (取得 groupId)
    Admin->>Backend: 在系統後台將 groupId 與「專案 PJ-xxx」進行綁定

    Client->>LineGroup: 發送訊息：「首頁按鈕點擊後沒有反應，請協助確認」
    LineGroup->>LineBot: 訊息同步
    LineBot->>Backend: Webhook: message 事件 (sender_name, text)
    Backend->>Backend: 寫入 project_line_messages 資料表
    Backend-->>Admin: WebSocket 即時推播至專案詳情 LINE 動態面板

    Backend->>AI: 語意分析: 提取重點與意圖
    AI-->>Backend: 判定為 Bug 回報，自動生成待辦 Task

    Admin->>Backend: 在內部系統打字點擊「回覆 LINE 群組」
    Backend->>LineBot: 呼叫 LINE Push Message API
    LineBot-->>LineGroup: 以官方助理身分推播：「已收到回報，工程師正在修復中」
```

## 6. 憑證 8 小時過期自動跳轉流程圖 (Auth & Expiration Flow)

```mermaid
graph TD
    classDef level1 fill:#f97316,stroke:none,color:white;
    classDef level2 fill:#0d9488,stroke:none,color:white;
    classDef level3 fill:#8b5cf6,stroke:none,color:white;
    classDef level4 fill:#ec4899,stroke:none,color:white;

    Login[使用者於 /login 輸入帳密]:::level1 --> AuthCheck{帳密驗證}:::level2
    AuthCheck -->|成功| IssueJWT[簽發 8 小時 JWT Token]:::level1
    AuthCheck -->|失敗| LoginError[顯示錯誤 Toast]:::level4

    IssueJWT --> ClientStore[前端儲存 Token 並啟動定時器 Timer]:::level3
    ClientStore --> NormalOps[正常操作各模組功能]:::level3

    NormalOps --> ExpireTrigger{8 小時時間到達 或 API 回傳 401}:::level2
    ExpireTrigger -->|到達臨界點 / 401| AutoClear[自動清空 localStorage 憑證]:::level4
    AutoClear --> AutoRedirect[前端無需手動刷新，自動跳轉至 /login 登入頁]:::level1
```
